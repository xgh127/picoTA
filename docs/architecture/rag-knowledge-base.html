一、架构总览

RAG 知识库采用三层架构：用户层（TA Agent / 实习生 / 导师）通过工具接口 search_knowledge_base 访问知识库层；知识库层基于 DurableMemoryStore 引擎进行 tag 精确匹配 + keyword 重叠度 检索；存储层以 6 个独立 markdown 文件 形式持久化在 .pico/memory/topics/ 下，每文件对应一个知识域。 整体不依赖任何外部向量数据库或 embedding 服务，完全本地运行。

二、数据流

当 TA Agent 需要参考知识库时，按以下链路执行：Agent 发起工具调用 → search_knowledge_base 解析查询 → DurableMemoryStore 读取 MEMORY.md 索引定位 topic → 加载对应 .md 文件中的全部笔记 → _tokenize 对查询和笔记进行中英文分词（中文支持 bigram/trigram）→ 按 tag 命中优先、 keyword 重叠次之、更新时间最后排序 → 返回 Top-N 结果给 Agent。整个链路在2ms 内完成。

    KB-->>TA: 格式化结果文本
    TA-->>Intern: 生成日报评估建议

三、存储结构

知识库以纯文件形式存储在项目 .pico/memory/ 目录下，天然支持 git 版本追踪。 MEMORY.md 是自动维护的索引文件，记录所有 topic 的元信息（标题、摘要、标签）。 每个 topic 对应 topics/{topic}.md 一个独立文件，内部以 YAML 风格的 header 记录元数据， ## Notes 下方以列表形式存放具体知识条目。这种设计让知识库人类可读、机器可解析、git 可 diff。

四、检索算法

检索引擎采用轻量级方案——不做 embedding 向量化，而是基于标签精确匹配和关键词重叠度进行排序。 查询文本先经过 _tokenize 分词：英文按 [A-Za-z0-9_]+ 拆分，中文按连续汉字序列提取 并额外生成 2-gram 和 3-gram 子串以提升召回率。排序优先级：先看是否有 tag 精确命中（最高优先级）， 再看 keyword 重叠数量，同分时优先返回更新条目。这种方案在 44 条规模下命中率 100%、耗时 < 2ms， 完全满足 TA 场景的实时性要求。 

flowchart LR
    Q["用户查询"] --> T["_tokenize"]
    T --> WT["英文: ASCII 分词
中文: 全文 + bigram/trigram"]
    WT --> M["tag 精确匹配"]
    WT --> O["keyword 重叠度"]
    M --> R["排序: tag_hit > overlap > recency"]
    O --> R
    R --> OUT["Top-N 结果"]
score = (exact_tag_match, keyword_overlap, recency)
  • exact_tag_match — 查询 token 是否命中 note 的 tags（布尔值，最高优先级）
  • keyword_overlap — 查询 token 与 note 文本的 token 交集数
  • recency — 笔记创建时间戳（ISO 时间，同分时更新者优先）

五、与 TA Agent 的集成

知识库通过两个注入点与 TA Agent 集成：一是 persona.py 中的 TA_PREFIX， 在系统提示词中告知 Agent 知识库的存在和使用方式；二是 tools.py 中注册的 search_knowledge_base 工具，Agent 在运行时按需调用，不占用 system prompt 空间。 知识库初始化由 python -m pico.ta.knowledge_base --seed 一次命令完成， 后续可通过增量更新的方式添加新知识。

九、实现亮点

亮点说明
零外部依赖 不上 embedding 模型、不接向量数据库、不调用外部 API，纯本地文件检索，单次查询 < 2ms
CJK 原生支持 中文检索不依赖 jieba 分词，通过 bigram/trigram 子串匹配实现高召回，支持中英文混合查询
文件即数据库 知识以 markdown 文件存储，人类可读、git 可追踪、可手动编辑，零学习成本
增量更新 知识库支持幂等写入，重复执行 seed 不会产生重复条目；新知识可通过 store.promote() 增量追加
与 Agent 正交 知识库以工具调用方式接入，不侵入 agent_loop.py 主循环，符合整个 TA 项目"不改主循环"的工程纪律
测试覆盖 8 个测试用例覆盖初始化、幂等、检索、过滤、状态查询全链路，确保代码可靠性
