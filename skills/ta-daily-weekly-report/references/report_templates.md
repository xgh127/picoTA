# 实习日报/周报模板

## 日报标准模板

```markdown
# 实习日报

## 1. 今日进展
- [今天完成了什么]

## 2. 证据/产物
- [文件 / 截图 / PR / 实验结果 / 提交记录 / 任务状态]

## 3. 遇到的问题与阻塞
- 问题：
- 影响：
- 需要确认：

## 4. 明日计划
- [明天的重点任务]
- [预期可验收产物]

## 5. 是否需要导师同步
- 判断：[不需要 / 建议常规同步 / 建议尽快同步]
- 原因：
- 建议同步内容：
```

## 周报标准模板

```markdown
# 实习周报

## 1. 当前整体进度
- 整体进度：[填写 0-100%，无法判断则写“待确认”]
- 进度依据：[来自里程碑、任务状态、实验产物或用户描述]

## 2. 本周进展
- 已完成：
  - [任务 1 + 证据]
  - [任务 2 + 证据]
- 进行中：
  - [任务 + 当前状态]
- 可验证产物：
  - [文件 / 截图 / PR / 实验结果 / 任务链接]

## 3. 遇到的问题与阻塞
- 问题：
- 当前影响：
- 已尝试方法：
- 需要确认：

## 4. 下周计划
- 重点目标：
- 具体任务：
  - [任务 1]
  - [任务 2]
- 可验收产物：
  - [产物 1]
  - [产物 2]

## 5. 实习收获
### 5.1 课程收获
- [本周学到的方法、工具、框架或项目理解]

### 5.2 分享心得体会
- [对项目推进、团队协作、问题定位或金融文档场景的体会]

## 6. 是否需要导师同步
- 判断：[不需要 / 建议常规同步 / 建议尽快同步]
- 原因：
- 建议同步内容：
```

## 示例表达

### 进度表达

- `整体进度：26%。依据：W1、W2 已完成，W3 当前完成 40%，按里程碑权重加权计算。`
- `整体进度：待确认。当前输入没有提供里程碑权重或完成比例，建议补充项目状态表。`

### 证据表达

- `证据：baseline_comparison.md 中记录了 latency、token、LLM calls 和 tree depth 指标。`
- `待补充证据：目前只描述“继续推进”，缺少文件、截图、实验结果或提交记录。`

### 导师同步表达

- `建议尽快同步导师：W3 已到期但未完成，且阻塞集中在跨文档共现实体的节点合并策略，需要导师确认边界标准。`
- `当前不需要额外同步：本周无明确阻塞，且昨天刚完成导师同步，保持正常节奏即可。`
